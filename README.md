# LifeCircle OS

The Operating System for Indian Families.

## Vision
LifeCircle helps Indian families manage:
- Medicines
- Parents
- EMIs
- Bills
- Insurance
- Household coordination
- Family responsibilities

## Technology
- Flutter
- FastAPI
- PostgreSQL
- Redis
- Docker
- GitHub Actions

## Branches
- main → Production
- develop → Active development
- feature/* → Features
- release/* → Releases
- hotfix/* → Production fixes
