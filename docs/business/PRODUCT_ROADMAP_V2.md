# Product Roadmap V2

## Current: Phase 7 & 8 (Launch Readiness)
- Internal Beta Certification.
- Enterprise documentation & Business modeling.

## Horizon 1: Public Beta (Next 3 Months)
- F001-F010 Design Partner Onboarding.
- Release of the `Emergency Module` to external testers.
- SOC2 Type I compliance scaffolding.
- Implementation of the flat-rate Stripe subscription flow.

## Horizon 2: General Availability (3-6 Months)
- Broad iOS and Android Store releases.
- Introduction of the `Medical Adherence` module (Prescriptions & Reminders).
- Cross-household sharing (e.g., divorced parents coordinating a child, adult children coordinating elderly care).

## Horizon 3: The Proactive System (6-12 Months)
- Integration of On-Device AI to predict routine responsibilities.
- Advanced Analytics Dashboard for families (e.g., visualizing the Peace Index over a year).
- Open API for IoT integrations (e.g., syncing smart pill dispensers with the Medical module).
