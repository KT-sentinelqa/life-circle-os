# Release Calendar & Maintenance Windows

## 1. Maintenance Windows
To minimize disruption to evening routines (the highest usage period for families), all planned backend maintenance that may cause sync downtime must occur during the global minimum usage window:
- **Tuesdays: 02:00 AM - 04:00 AM (UTC)**

*Note: Because the app is offline-first, users will likely not notice this downtime unless they attempt to invite a new user or explicitly wait for a live sync.*

## 2. Release Cadence
- **Patches (vX.Y.Z):** Released continuously as needed for critical bug fixes.
- **Minor Updates (vX.Y.0):** Released on a 4-week cycle. Release Candidates are cut on the 3rd Wednesday of the month, tested for 1 week, and deployed on the 4th Wednesday.
- **Major Updates (vX.0.0):** Scheduled bi-annually. Requires a minimum 4-week Beta testing period.
