# LifeCircle OS — Microcopy Guide

**Version:** 1.0 | Phase 6.2 Experience Architecture
**Purpose:** Words are design. Every string of text must reduce cognitive load, not increase it.

---

## Voice & Tone
LifeCircle OS speaks like **a trusted older sibling** — someone who knows the family well, is calm under pressure, never judges, and always has useful information without being overwhelming.

| Quality | We Are | We Are Not |
| :--- | :--- | :--- |
| Calm | *"Papa's medicine hasn't been confirmed yet."* | *"ALERT: Critical medicine missed!"* |
| Honest | *"You're offline. Changes will sync when connected."* | *"Connection lost! Data may be at risk."* |
| Direct | *"I'll handle it"* | *"Click here to acknowledge the exception and update the responsibility status"* |
| Warm | *"Everything is covered."* | *"No exceptions found. System status: OK."* |
| Human | *"Can you take this one?"* | *"Backup owner action required."* |

## Core Strings by Screen

### Peace Index
| State | Microcopy |
| :--- | :--- |
| Score ≥ 80 | *"Everything is covered."* |
| Score 50–79 | *"A few things need attention."* |
| Score < 50 | *"Your family needs you right now."* |
| Empty (no tasks) | *"Your family hasn't added any responsibilities yet."* |
| Loading | *"Checking in with your family…"* |

### Responsibility Tile
| State | Microcopy |
| :--- | :--- |
| Owned by self | *"You're handling this"* |
| Owned by other | *"[Name] has this covered"* |
| Overdue | *"This was due [time ago]"* |
| Completed | *"Done · [Name]"* |
| No owner assigned | *"Nobody is assigned yet. Add an owner."* |

### Exception Alert
| State | Microcopy |
| :--- | :--- |
| Primary missed | *"[Name] hasn't confirmed this yet. Can you take this one?"* |
| Escalation | *"[Responsibility] hasn't been confirmed for 2 days. This might need your attention."* |
| CTA — Primary | *"I'll handle it"* |
| CTA — Delegate | *"Delegate"* |

### Offline / Sync
| State | Microcopy |
| :--- | :--- |
| Offline | *"You're offline. Changes will sync when connected."* |
| Syncing | *"Syncing family data…"* |
| Sync error | *"Sync paused. Will retry automatically."* |
| Sync restored | *(No message. Silence = success.)* |

### Onboarding

## Universal Rules for Writers
1. **Never use the word "task."** Use "responsibility." The word carries weight.
2. **Never use "Error."** Use "Something went wrong. We're on it."
3. **Never use passive voice for important actions.** Not *"The responsibility was completed"* — *"Rajesh completed this."*
4. **Never end a sentence with punctuation in a score or badge.** Numbers breathe.
5. **Celebrate silence.** *"Nothing needs your attention right now."* is a win state. Design it like one.
